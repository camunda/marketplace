Migrate from Camunda 7 to 8 with VanillaBP: seamless, flexible, and low-risk. Run both platforms in parallel and avoid "big bang" migrations.

## Features

### Run Camunda 7 and 8 with the same business code

VanillaBP enables Camunda 7 and 8 to use the same business code base. 
Once lifted to VanillaBP, migrating from Camunda 7 to 8 is just a matter of configuration.

### Operate both platforms in parallel

Continue running Camunda 7 processes while introducing Camunda 8 processes using an adapter-based co-existence model. No need for "big bang" migrations.

### Migrate at the process instance level

Smoothly transition of workflows from Camunda 7 to 8, even across running process instances. Keep existing process instances of your application running in Camunda 7 while new instances will be created in Camunda 8.

### Simplify migration complexity

Abstract process logic and decouple infrastructure to avoid effects of tightly coupled legacy architecture. You will also benefit from this for upcoming changes such as the switch from gRPC to REST APIs.

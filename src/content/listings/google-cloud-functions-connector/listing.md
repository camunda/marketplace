Retrieve a list of functions and invoke a function from Google Cloud Functions.

## Features

### List Functions

Visibility into your deployed functions is essential for effective management. Use this feature to get an up-to-date list of all your Google Cloud Functions. This is crucial for monitoring the status, availability, and performance of your functions, allowing you to make informed decisions about scaling, error handling, and deployment.

### Invoke Function

Serverless architectures are all about on-demand, event-driven execution. By supporting direct function calls, this Connector allows you to execute specific Google Cloud Functions based on triggers within your workflow. This can be invaluable for real-time data processing, task automation, and even complex orchestration scenarios involving multiple cloud services.

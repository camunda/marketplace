Trigger ServiceNow flows, manage records in any data table, and handle incidents as native steps directly from Camunda.

## Features

### Bi-directional integration between ServiceNow and Camunda

Seamless integration between ServiceNow flows and Camunda processes to bring orchestration capabilities to ServiceNow. Requires the Camunda Spoke to be installed in ServiceNow.

### Manage records within ServiceNow

Create, read, modify, and delete any ServiceNow record from a Camunda-based process modeled in BPMN.

### Secure by design

Uses only supported, public APIs and follows enterprise-grade security best practices.

### Easy and free to use

Straightforward installation and easy-to-follow configuration steps. No additional license costs.

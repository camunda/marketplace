## Features

### Create or Send Docusign Envelope

Automate the process of document signing directly from Camunda process using this connector. You can easily initiate the process of creating and sending document envelopes. It allows you to generate and dispatch envelopes for documents that require signatures, also one can perform various operations like getting envelope information and downloading documents from envelopes. This features simplifies document workflows.

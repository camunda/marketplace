*Empower conversational agents with integrated tools*

Integrate AI chat agents into business processes, enabling automated conversations and tool execution for greater efficiency.

## Features

### Facilitate human-AI interaction

Enable interaction between AI and people by processing chat requests, capturing user feedback, and triggering actions such as sending emails or initiating tasks via embedded forms.

### Deliver AI-driven chat experiences

This modular and extensible solution enables teams to quickly implement AI-driven chat experiences.

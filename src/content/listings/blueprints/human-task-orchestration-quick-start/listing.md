*Human Task Orchestration Quick Start*

Incorporate human work within automated business processes using BPMN and Camunda.

## Features

### Task Assignment and Management

Streamlines the assignment and management of human tasks, improving workflow clarity and accountability.

### User Task Forms

Utilizes user task forms to collect and validate input from human task participants, enhancing data accuracy and process efficiency.

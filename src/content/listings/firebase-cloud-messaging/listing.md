Discover how Firebase Cloud Messaging can help you integrate your Camunda BPMN workflows with any device or topic and send notifications with ease. Learn more about the benefits and features of this cross-platform messaging solution.

## Features

### Mobile Device Token Notifications

Deliver Firebase Cloud Messaging notifications to a single or multiple device tokens with ease.

### Topic Notifications

Utilize Firebase Cloud Messaging to deliver notifications to a topic effortlessly. This enables a larger number of users to receive the notifications.

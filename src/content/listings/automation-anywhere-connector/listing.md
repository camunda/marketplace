Integrate Camunda's leading process orchestration with Automation Anywhere's RPA capabilities. Harness the power of seamless automation across both modern and legacy systems. Efficient task queuing and precise outcome retrieval made easy.

## Features

### Add Work Item to the Queue

Through Camunda, you can directly queue tasks for Automation Anywhere, enabling RPA actions, particularly for legacy systems that lack direct integration capabilities.

### Get Work Item Result from Queue by ID

Retrieve specific task outcomes from Automation Anywhere using unique identifiers. This feature ensures accurate tracking and reporting of RPA actions across all systems, whether modern or legacy.

Orchestrate file operations on an FTP server as part of Camunda-based processes.

## Features

### Copy File

Automate the process of file duplication on an FTP server directly from Camunda processes. Use this feature in processes that require backup or versioning, enabling automatic file copying to designated locations.

### Copy Folder

For automated processes that require folder-level duplication, this feature enables you to copy entire folders on an FTP server. This feature can be used for backup or migration scenarios where the integrity of folder structures must be maintained.

### Create Folder

Automate folder creation on an FTP server. In processes that require new data repositories or organizational units, use this feature to create new folders as part of the automated process.

### Delete File

Incorporate automatic file deletion into workflows. Whether you're running data-cleansing operations or need to remove temporary files, this feature allows you to delete files from an FTP server as a step in your Camunda-based processes.

### Delete Folder

Automate the removal of entire folders from an FTP server. This feature is useful in scenarios such as data purging or deprovisioning, where you need to remove redundant or outdated data repositories.

### List Files

Retrieve a list of files from a specific directory on an FTP server within automated processes. In content audit or reporting scenarios, use this feature to generate real-time file lists for further action or review.

### List Folders

Obtain a list of folders from an FTP server directly within Camunda-powered business processes. This feature is ideal for scenarios that require a snapshot of available data repositories for tasks such as automated report generation or compliance checks.

### Move File

Automatically move files between folders on an FTP server. This feature is useful in automated file sorting or archiving processes where you need to organize data based on certain criteria or events.

### Move Folder

For processes that require folder-level organization, this feature allows you to move entire folders within an FTP server. This feature is ideal for large-scale data migration or reorganization tasks.

### Read File

Integrate the content of files from an FTP server directly into your Camunda processes. In data parsing or transformation tasks, use this feature to read file content for further processing or decision-making.

### Write File

Automatically write or append content to a file on an FTP server. Whether you're generating logs, reports, or any other kinds of files, this feature enables you to create or update files as a part of your business processes.

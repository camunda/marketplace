Generates barcodes directly within a Camunda process, supporting formats including Aztec, Codabar, Code 128, Code 39, Code 93, Data Matrix, EAN-8, EAN-13, ITF, PDF417, QR Code, UPC-A, and UPC-E.

## Features

### Generate barcodes

Generates barcodes in a range of formats, from a single connector step.

### Generate QR codes

Generates a QR code for scannable data such as URLs or product information.

### Generate EAN-13 barcodes

Generates an EAN-13 barcode for retail product identification.

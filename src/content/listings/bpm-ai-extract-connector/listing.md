Automatically extract information from unstructured input data given a JSON schema.

## Features

### Flexible, AI-Powered Data Extraction

Harness the power of the latest AI models to extract key information from unstructured data with precision.

### Customizable Output Schema

Tailor the extracted data output to fit your requirements with a customizable JSON schema. Define what information to extract and how it should be structured, ensuring that the data feeds into your process exactly as needed.

### Multiformat Support

Accept documents and data in various formats including PDFs, images, and audio. You can input documents via file paths or web URLs, making the Connector adaptable to a wide range of sources and ensuring seamless integration into your existing processes.

### Accountable, Hallucination-free Extraction

Optionally use specialized extraction models instead of generative AI (such as OpenAI's GPT-4) to guarantee verbatim data extraction from your documents. This ensures that the data is copied precisely, without "hallucinations" or inaccuracies, providing you with accountable information for your workflows.

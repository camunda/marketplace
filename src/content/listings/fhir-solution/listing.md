FHIR Connector for Camunda automates clinical workflows with SMART-on-FHIR security, real-time EHR triggers, and native FHIR R4 resource orchestration.

## Features

### Orchestrate standard FHIR resources

Native support for standard FHIR resources (Patient, Observation, Encounter, Claim, and others) via a drag-and-drop interface.

### Secure access with SMART-on-FHIR

Pre-configured OAuth2 and OIDC authentication patterns to ensure HIPAA-compliant data access.

### Map FHIR data to process variables

Simplifies the transformation between FHIR JSON structures and Camunda process variables.

### Trigger processes from clinical events

Enables Camunda to listen for FHIR resource changes via subscriptions to trigger automated processes instantly.

Integrate Microsoft Azure Blob Storage into your Camunda processes by retrieving information about blob containers and uploading data to them.

## Features

### List Blob Containers

Organizing your data starts with understanding the storage containers you have. Use this feature to quickly fetch a list of all blob containers, making it easier to plan your data architecture, carry out migrations, or perform backups.

### List Blobs

Knowing what's in each container is as crucial. This feature allows you to list all blobs in a specific container, making it simpler to manage data, check versions, and ensure that no redundant or unnecessary data is occupying valuable storage space.

### Get Blob

This feature allows you to retrieve individual blobs for data analytics, machine learning models, backup purposes and more. This feature ensures that you can pull the data you need when you need it.

### Update Block Blob

Keeping your data up-to-date is essential. This feature allows you to overwrite or update chunks of a blob without affecting the rest of the blob. This is highly useful in scenarios such as real-time data streaming, updating log files, and patching content in your cloud storage.

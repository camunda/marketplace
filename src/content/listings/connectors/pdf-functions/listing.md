Automate many different functions with PDF files.

## Features

### Extract Pages from a PDF

Extract pages from a PDF using an expression such as "4-6,10-11,25,23-n".

### Merge PDFs

Merge a list of PDF files to produce a single PDF file.

### Watermark a PDF

Add a watermark to each page of a PDF.

### Convert Images to a PDF

Product a single PDF from a list of images.

### Convert PDF to Images

Use a PDF to product one image per page.

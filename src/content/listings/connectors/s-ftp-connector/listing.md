Publish a file to an S/FTP server or download a file from an S/FTP server.

## Features

### Producer (Upload a File)

This feature is invaluable when your process involves regularly transferring sensitive or bulky files from a local system to a remote SFTP server. Whether it's customer data, software updates, or backup files, securely upload them directly through your Camunda process without manual intervention.

### Consumer (Download a File)

Easily download files from an SFTP server to a local system using this feature. Ideal for workflows that need to acquire remote data for local processing, analytics, or archival. For example, you can automate the download of daily sales reports or configuration files for further analysis or use within other processes.

*Enable connectivity with other applications using NATS messaging platform.*

Send messages to topics on NATS servers to enable connectivity to other systems using NATS.

## Features

### Publish Message

Enable Camunda workflows to orchestrate activities throughout the enterprise via publishing free form messages to NATS topics.

Orchestrate file and document-heavy processes with Camunda and Amazon S3.

## Features

### Upload a File

Quickly and securely upload files to an Amazon S3 bucket with a simple integration in your Camunda process, streamlining cloud storage and file management.

### Delete a File

Keep your Amazon S3 storage clutter-free by integrating the ability to delete files directly from Camunda-based processes, ensuring efficient management of cloud resources.

### Download a File

Access and download files that are stored in Amazon S3 from Camunda-based business processes, enhancing data management efficiency.

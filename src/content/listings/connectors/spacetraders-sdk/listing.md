An SDK to play SpaceTraders from a Camunda process.  It makes the interaction with the API easy by providing one connector for all endpoints, from purchasing a ship to miring ore.

## Features

### Interact with the SpaceTraders API

Allows you to send HTTP requests to the SpaceTraders API. It covers all API endpoints from purchasing a ship to mining ore. All required and optional parameters can be configured.

### Fun

Do you like games, space simulations, or puzzles? SpaceTraders is a great game and the connector is your first step into this new world. Learn more about the game at https://spacetraders.io/.

Orchestrate human work that's managed in Microsoft 365 To Do. Perform operations on task lists, tasks, and check list items.

## Features

### Task Operations

Perform task-based operations, including getting a task, creating a task, updating a task, and deleting a task.

### Task List Operations

Perform operations on a task list, including getting a list of task lists, and getting, creating, updating, and deleting a specific task list.

### Check List Operations

Perform operations on a check list, including getting a list of check list items, and getting, creating, updating, and deleting items in a specified check list.

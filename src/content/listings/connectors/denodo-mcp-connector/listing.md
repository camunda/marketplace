Connect Camunda process orchestration with the Denodo Platform via Model Context Protocol (MCP). Enable secure, governed data retrieval across enterprise sources to power intelligent processes.

## Features

### Active Context for Agentic Processes

Expose live, semantically unified enterprise data products via the Model Context Protocol (MCP) to supply the exact contextual data required for non-deterministic AI agent reasoning and automated decisioning.

### Runtime Governance & Zero-Trust Security

Centrally enforce access policies, row-level filtering, column masking, and data lineage at query execution, guaranteeing that process steps and AI agents only consume data they are explicitly authorized to view.

### Universal Connectivity Across 200+ Sources

Connect to cloud warehouses, lakehouses, databases, SaaS applications, and legacy systems through a single logical interface without copying data or managing point-to-point ETL pipelines.

### Zero-Copy Performance & Pushdown Optimization

Execute high-performance cross-source queries using intelligent query pushdown and acceleration, delivering real-time data access while reducing latency and storage duplication.

### Shared Business Vocabulary & Reusable Data Products

Deliver curated, business-meaningful data products with built-in trust and semantic consistency across all reporting, application, and automated process steps.

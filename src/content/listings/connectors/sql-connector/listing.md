Simplify data exchange with MySQL, MSSQL, MariaDB, and PostgreSQL databases. Seamlessly integrate database operations into your Camunda-based processes.

## Features

### Direct Database Integration

This Connector allows direct reading and writing of data within MySQL, MSSQL, MariaDB, and PostgreSQL databases, simplifying data exchange in Camunda processes.

### Enhanced Workflow Automation

You can execute various process blueprints and use cases without extra installation or development effort.

### Improved Security and Maintenance

This Connector reduces complexity, enhances security, and lowers maintenance costs by integrating database operations within Camunda.

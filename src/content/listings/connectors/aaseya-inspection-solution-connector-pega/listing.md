The Aaseya Inspection Solution Connector enables seamless process execution and data exchange between Pegasystems and Camunda, ensuring end-to-end process automation and enhanced user experiences.

## Features

### Get Tasks from a Project

Retrieve all tasks within a Pega project, enabling Camunda processes to perform or complete inspection tasks.

### Get a Task by ID

Fetch specific task details from Pega, allowing Camunda to perform tailored actions such as updates, notifications, and subsequent task creation.

### Create a Task

Directly create new tasks within a Pega Inspection Case from a Camunda process. This feature is ideal for automating project milestones or triggering sub-tasks.

### Get Inspections

Enumerate all available Pega Inspections, facilitating dynamic routing or decision-making within Camunda-based processes.

### Create an Inspection in Pega

Automatically create a new Inspection case in Pega; for example, initiate a new Fire Inspection or Safety Inspection directly from a Camunda-based process.

### Cancel a Inspection

Cancel an existing Inspection process in Pega. This feature allows Camunda-based processes to manage Inspection lifecycles, including their cancellation.

*Automate multi-channel communications with Brevo*

Send email, SMS, and WhatsApp notifications using the Brevo API for process automation and real-time communication.

## Features

### Automate customer communication

Automatically routes requests based on notification type, reducing complexity in BPMN process design.

### Multi-channel notifications

Send notifications via email, SMS, and WhatsApp from a single connector in Camunda-based business processes.

### Easy integration with Brevo API

Seamlessly integrates with Brevo API using simple configuration and secure API key authentication.

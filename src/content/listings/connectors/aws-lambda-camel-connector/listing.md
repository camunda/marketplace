This Connector uses Apache Camel with AWS Lambda to retrieve a list of functions and invoke a function that exists in AWS.

## Features

### List AWS Lambda Functions

Having an accessible list of all AWS Lambda functions deployed on your AWS account is crucial for orchestration and auditing. It allows for dynamic function selection and invocation, thus making your processes more versatile and adaptive to changing needs.

### Invoke AWS Lambda Function

Direct invocation of AWS Lambda functions from Camunda via Apache Camel offers you real-time, serverless compute capabilities. This feature is particularly useful for scenarios such as data transformation, event-driven processing, and other tasks that require scalable, on-the-fly computation.

The JIRA Connector can be used for performing various kind of jira operations using templates from your BPMN process.

## Features

### Create Epic

Create an epic via camunda.
Example: Whenever an idea passes the validation phase in your automated ideation process, this feature will automatically create a corresponding Epic in Jira. Capture high-level project objectives without manual intervention, allowing teams to focus on execution.

### Create Issue

In an automated bug-tracking process, use this feature to directly generate a Jira issue when a new bug is detected. Eliminate manual steps and ensure quicker response times for issue resolution.

### Get Board Details

If your automated process requires an overview of project statuses, this feature will fetch Jira board details for you. Use the real-time data to make informed decisions within your Camunda workflows.

### Get Issue

In processes that require issue tracking and monitoring, this feature fetches the most current information on a Jira issue. Update workflow branches or notifications based on the real-time status of an issue in Jira.

### Get Sprint Details

For agile processes that sync with development cycles, use this feature to pull the latest sprint details from Jira. Incorporate this data into your automated workflows to align sprints with business objectives.

### Update Epic

When a milestone is reached or modified in your automated process, this feature allows you to update the corresponding Epic in Jira. Keep your high-level objectives in sync without manual updates.

### Update Issue

In an automated customer support workflow, use this feature to update Jira issues based on customer feedback or resolution status. Keep all stakeholders in the loop without requiring manual intervention.

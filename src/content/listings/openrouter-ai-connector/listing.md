Call popular AI models and switch between models to test performance and response quality.

## Features

### Unified access to multiple AI models

Call popular AI models such as OpenAI GPT, Meta Llama, Google Gemini, Mistral, and Qwen. Switch between models effortlessly to test performance and response quality.

### Simple API key configuration

Authenticate securely with your own OpenRouter API key, managed through Camunda secrets. Start experimenting quickly without complex setup or billing constraints.

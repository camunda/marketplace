Automatically translate documents, audio, and text from process variables into any language.

## Features

### Seamless Text Translation

Automatically convert text to your desired language with built-in translation models, enabling clear and accurate communication across borders.

### Multimodal Support

Accept input data in various forms and modalities including PDFs, images, and audio. You can input documents via file paths or web URLs, making the Connector adaptable to a wide range of sources and ensuring seamless integration into your existing processes.

### Local Translation Model Support

Utilize local translation models to keep translations fast and secure without relying on external services.

Integrate Camunda with Google Drive to automate folder and file creation. This Connector is ideal for archiving, data collection, and generating standardized documents within orchestrated processes.

## Features

### Create Folder

Automatically create folders in Google Drive right within Camunda, serving as organized storage destinations for subsequent process steps, such as archiving documents or collecting data files.

### Create File from Template

Leverage Camunda to create files in Google Drive based on predefined templates. This feature is ideal for generating standardized documents such as contracts, invoices, or reports that are integral to your business-critical processes.

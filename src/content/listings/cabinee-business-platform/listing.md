A highly adaptable business platform, Cabinee combines a ready-to-use end-user application with native Camunda integration to automate virtually any process in days, not months.

## Features

### Organize processes in one workspace

Combine workspaces, request types, statuses, and related processes with documents in a shared space.

### View all process data in one card

Shows data, assignees, status, and processing history in a single, unified card, so every process detail lives in one place.

### Adjust forms by process type and status

Adjusts task and request form availability by type and status, adapting the interface to each process without changing code.

### Manage tasks and approvals out of the box

Assigns, executes, and controls user tasks within the process, with out-of-the-box execution control and approvals.

### Track activity and events automatically

Tracks comments, events, and a complete history of incoming and outgoing correspondence.

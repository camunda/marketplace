Using the Change Streams feature in MongoDB, monitor updates in databases or collections and start process instances or send messages to Camunda to drive process instances.

## Features

### Monitor for MongoDB updates

Monitor for updates in databases or collections and start Camunda process instances or send messages to process instances using this connector.

Automate creation and management of ServiceNow incidents directly from Camunda processes. Ideal for ITSM workflows, error handling, and incident lifecycle automation.

## Features

### Simplified configuration

Preconfigured for the "incident" table. No manual setup needed.

### Incident Lifecycle Made Easy

Create, read, update, and delete ServiceNow incidents directly in a Camunda process.

### Seamless Error Handling

Log incidents directly to ServiceNow when a Camunda process fails.

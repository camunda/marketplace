Start ServiceNow Flow Designer flows from Camunda processes to orchestrate approvals, fulfillment, or catalog workflows using REST calls and correlation keys.

## Features

### Trigger ServiceNow flows

Start any ServiceNow Flow Designer flow directly from a Camunda process.

### Flexible request configuration

Supports POST, GET, PUT, PATCH, and DELETE with headers, query parameters, and custom payloads.

### Seamless process orchestration

Combine ServiceNow workflows with Camunda for powerful end-to-end business processes.

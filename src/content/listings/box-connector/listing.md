Manage folders and files that are stored on Box directly from business processes that are orchestrated by Camunda.

## Features

### Upload a File

Easily upload files from business processes to Box, enabling centralized storage and accessibility for all stakeholders involved.

### Download a File

Retrieve files that are stored on Box and integrate them into Camunda-based processes for tasks such as approvals, reviews, and audits.

### Move a File

Reorganize assets on Box by moving files to different folders, ensuring logical organization and streamlined file management.

### Create a Folder

Generate folders dynamically during process execution so you can categorize files on Box.

### Delete a Folder

Automate the removal of empty or redundant folders on Box so your storage structure is optimized and clutter-free.

### Search for Files and Folders

Quickly locate specific files or folders on Box by leveraging the search functionality directly within Camunda-based processes. This feature reduces time spent manually locating critical assets.

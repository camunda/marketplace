Create a PDF from any Microsoft Office or Open Office document

## Features

### Create a PDF

Create a PDF from Microsoft Office or an Open Office document. A process variable provides the document as a file reference file storage (https://github.com/camunda-community-hub/zebee-cherry-filestorage) or via a load connector.

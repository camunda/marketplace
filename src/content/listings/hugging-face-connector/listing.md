Integrate popular machine learning models into business processes using the Hugging Face Inference API.

## Features

### Model Flexibility

Seamlessly integrate any Hugging Face model into your Camunda processes. Select from models such as GPT-3, BERT, and DistilBERT to enhance your automated processes with cutting-edge AI capabilities.

### Customizable AI Connector

Tailor the Camunda Hugging Face Connector to meet specific process requirements by specifying options such as model choice, randomness control, token limits, and output preferences, ensuring precise alignment with application needs.

### Simplified User Interface Design

Create custom templates that streamline the user interface for end users, displaying only essential input fields and hiding the complexity of the underlying AI configurations, thus enhancing user experience and promoting adoption.

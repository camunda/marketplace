Take advantage of unlimited scalability with relational semantics by connecting you Applications and workflow to Google’s NewSQL database i.e) Cloud Spanner with the help of Acheron’s Cloud Spanner Connector

Elevate your Camunda workflows with the ‘Cloud Spanner Connector’ by Acheron. Seamlessly integrate Camunda with Google Cloud’s NewSQL database, Cloud Spanner. Efficiently manage data by creating tables, inserting, updating, and deleting data, and retrieving records with advanced filtering options. Achieve limitless scalability and relational semantics for your applications and workflows with our Cloud Spanner Connector.

Features

Seamless Integration

Connect Camunda with Google Cloud Spanner, bridging the gap between workflow automation and Google’s NewSQL database.

Table Management

Create new tables within your specified database, optimizing data organization for your workflow applications.

Data Insertion

Insert data into Cloud Spanner tables with ease, ensuring efficient data population for your applications.

Data Updates

Update data in tables based on specified conditions, maintaining data accuracy and relevance.

Data Deletion

Remove data from tables based on given conditions, enhancing data hygiene and compliance.

Data Retrieval

Retrieve data from Cloud Spanner tables with support for Limit, Sort, and Filters, enabling precise data access.

Scalability

Take advantage of Cloud Spanner’s unlimited scalability, perfect for handling evolving data needs.

Data Security

Leverage Google Cloud Spanner’s robust security features to safeguard your data within Camunda BPMN workflows.

Enhanced Efficiency

Boost workflow efficiency by seamlessly integrating Cloud Spanner capabilities into your Camunda BPMN processes.

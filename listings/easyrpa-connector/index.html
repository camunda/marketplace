easyRPA Connector

IBA Group Partner open-source

Use in SaaS Use Self-Managed Contact

Orchestrate easyRPA robots with help of Camunda-based business process

Enhance your business process automation with the easyRPA Connector for Camunda. Integrate easyRPA bots into Camunda processes to automate tasks and streamline operations.

Features

Start New Robot

This function allows you to queue tasks for an RPA bot. After the bot initiates the process, it returns the process ID to Camunda, allowing the process to track the bot’s status and receive the data it produces.

Get Robot Status

Use the Get Status feature to monitor the current status of RPA tasks directly from your Camunda process. This functionality provides real-time updates, enabling informed decision-making, effective error management, and the initiation of follow-up actions for seamless business operations.

Get DataStore

Use the Get DataStore function to retrieve information about a datastore using its mnemonic. This feature allows you to access detailed information about the specified datastore, facilitating efficient data management and retrieval within your processes.

Get item from DataStore

Use the Get item from DataStore function to locate data produced by the robot and stored in the datastore by file name. This feature allows you to quickly retrieve and use information generated by your RPA bots based on the specified file name.

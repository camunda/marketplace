Securely orchestrate file and folder operations on remote servers as part of Camunda processes.

Features

Copy File

Automate the process of copying files from one location to another on an SFTP server. This feature is ideal for backup procedures, data synchronization, and sharing information between different applications.

Copy Folder

Enable automated folder copying within an SFTP server for use cases such as cloning entire directories for backup or migration, or for initializing new environments.

Create Folder

Automate the creation of new folders on an SFTP server. This feature can be used for processes that set up new project structures, for organizing files, or for preparing storage for incoming data.

Delete File

Automate the process of deleting specific files from an SFTP server. This operation is essential for data cleanup, compliance, and archiving tasks where certain files need to be removed.

Delete Folder

Automatically delete entire folders from an SFTP server. This feature is ideal for purging outdated or unnecessary directories as part of automated data management processes.

List Files

Automatically list all files in a specified folder on an SFTP server for scenarios such as inventorying assets or preparing for batch operations, or for monitoring the state of directories.

List Folders

Retrieve a list of all folders within a specified directory on an SFTP server. Use this feature for tasks involving folder navigation, data organization, and workflow logging.

Move File

Move files from one folder to another on an SFTP server to reorganize data, archive folders, and transition files through different stages of a workflow.

Move Folder

Move entire folders within an SFTP server for tasks such as bulk data migration, restructuring directories, and automating deployment procedures.

Read File

Retrieve file content from an SFTP server. This feature can be used for tasks such as data validation, file processing, or triggering actions based on the content of a file.

Write File

Automate the process of writing data to a file on an SFTP server. This feature is essential for creating logs, updating configuration files, and storing processed data.

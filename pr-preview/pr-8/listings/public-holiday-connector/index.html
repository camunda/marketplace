Public Holiday Connector

Bastian Körber Community

Use in SaaSUse Self-Managed Contact

Integrate public holidays and long weekends seamlessly into Camunda processes with the Public Holiday Connector. Leverage Nager.Date API to keep your global teams and processes in sync with over 100 countries’ holiday schedules.

Features

Query Public Holidays

Need to know when public holidays are in a specific country for scheduling work or events? This feature allows you to query the Nager.Date API to find the public holidays in over 100 countries, ensuring you never plan critical activities on a non-working day.
